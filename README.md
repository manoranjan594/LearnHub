# LearnHub - Online Learning Platform

A full-featured online learning platform with courses, lectures, quizzes, assignments, progress tracking, and discussion forums.

## Features

- **User Profiles** – Sign up, sign in, edit profile
- **Course Catalog** – Browse and explore courses
- **Course Enrollment** – Enroll in courses with one click
- **Lectures** – Structured lessons with mark-as-complete
- **Quizzes** – Interactive quizzes with scoring
- **Assignments** – Track assignment completion
- **Progress Tracking** – Visual progress per course
- **Discussion Forums** – Post and view discussions per course

## How to Run

1. Open `index.html` in a web browser
2. Create an account or sign in
3. Browse courses and enroll
4. Access lectures, quizzes, assignments, and forums

- localStorage for persistence (no backend required)
- Responsive design
